The basics

How extensions work

Repositories

A repository is a signed repo.json index that lists plugins and where to fetch them. One repository can hold dozens of plugins.

Plugins

Each plugin adds one source or provider — a streaming site, an anime index, an IPTV playlist, a sports feed. Install only the ones you actually use.

Shortcodes

Instead of pasting a long URL, you type a shortcode such as pluginstream. The app resolves it to the curated repository bundle.

Auto-indexing

After you add a repository, PluginStream fetches its index automatically and drops every plugin into a browsable list — no restart, no manual refresh.

Setup guide

Add repositories in six steps

Works the same on every PluginStream build.

  1. Open the Extensions panel

    Go to app Settings (⚙️). Scroll down and select the Extensions tab.

  2. Open the repository menu

    Tap the + Add Repository button in the bottom-right corner.

  3. Enter the shortcode

    In the "Repository URL or Shortcode" field, type:

    pluginstream

    It is case-insensitive — uppercase or lowercase both work.

  4. Confirm the repository

    Tap "Add repository", then confirm by tapping "Add repository" again on the popup.

  5. Wait for auto-indexing

    A toast notification appears once loading finishes, and every repository shows up in the list automatically.

  6. Download plugins

    Tap any Repository Card to expand its plugins, then tap the Download (⬇️) icon next to the plugin you want.

Good to know

A few details that save time once you start adding repositories.

Visit pluginstream.pages.dev
  • Shortcodes are case-insensitive — pluginstream, PluginStream and PLUGINSTREAM all resolve to the same bundle
  • The download icon turns into a checkmark once a plugin installs successfully
  • Any single repository below can be added on its own — the shortcode is just a shortcut for the whole bundle
  • Repositories are community-maintained. PluginStream only indexes them — it does not host any content
